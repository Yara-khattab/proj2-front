# 📚 Online Library

An online library front-end project built using **HTML5** and **CSS3**.
This project was developed as part of my learning journey with **SEF Academy**.

---

## Project Overview

Online Library is a front-end website that represents a digital library
showcasing various types of books in a clean, organized, and user-friendly design.

The project focuses on presenting book categories and improving front-end
development skills using only HTML and CSS.

---

## 🛠️ Technologies Used

- **HTML5** – for structuring the website content
- **CSS3** – for styling, layout, and visual design

---

## 📂 Book Categories Included

- Fiction
- Non-Fiction
- Science
- Technology
- History
- Novels
- Educational Books

---

##  Features

- Semantic HTML5 structure
- Clean and simple user interface
- Organized book sections and categories
- Responsive layout for different screen sizes
- Easy navigation between sections

---

## 🎯 Project Purpose

- Practice HTML5 semantic elements
- Enhance CSS3 styling and layout skills
- Apply front-end concepts learned during SEF Academy training
- Build a real-world front-end project for the portfolio
